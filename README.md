## Featured Projects

### 🧠 DeepWorkAI — Full-Stack Productivity Ecosystem

A privacy-focused productivity platform that predicts burnout from work-session behaviour, combining a Kotlin backend, an Android client, and a Python ML microservice.

**Problem:** Productivity apps track time but give no early warning when a user's focus quality is degrading toward burnout.

**What I built**
- Designed a **scalable Ktor REST API** in Kotlin backed by **PostgreSQL** and **Exposed ORM**, with **JWT authentication** securing session and task data
- Built an **AI-driven burnout prediction pipeline** in Python (scikit-learn, Pandas) that processes user session histories to compute real-time performance scores
- Developed the **Android client with Jetpack Compose**, including custom Canvas animations and Vico Charts for visualising focus-stability metrics
- Integrated a **context-aware LLM assistant** via the HuggingFace Inference API (Qwen-2.5) for personalised, data-driven focus recommendations

`Kotlin` `Ktor` `PostgreSQL` `Exposed ORM` `JWT` `REST API` `Python` `scikit-learn` `Jetpack Compose` `LLM Integration`

🔗 **[View Repository →](https://github.com/VaibhavSharmaggwp/DeepWorkAI-FullStack)**

### 🛣️ Smart Pothole Detection — Android + Computer Vision

An Android application that detects road potholes automatically from the camera feed and reports them with precise location data.

**Problem:** Manual pothole reporting is slow and unreliable, leaving road authorities without accurate, current data on road conditions.

**What I built**
- Architected the app in **Kotlin using MVVM and Clean Architecture**
- Built the camera pipeline with **CameraX and OpenCV** for frame preprocessing
- Ran **on-device ML inference with TensorFlow Lite and GPU acceleration**, cutting inference latency by **15%**
- Integrated the **Google Maps SDK with GeoJSON** to visualise 100+ pothole locations
- Implemented energy-efficient location tracking with **FusedLocationProvider**

`Kotlin` `MVVM` `Clean Architecture` `TensorFlow Lite` `CameraX` `OpenCV` `Google Maps SDK` `Firebase`

🔗 **[View Repository →](https://github.com/VaibhavSharmaggwp/Pothole_Detection)**
